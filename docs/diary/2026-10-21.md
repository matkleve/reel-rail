# 2026-10-21 — Phase 1

- Spec came in German; the user asked for **everything in English** (UI copy,
  code, docs).
- User offered the `grundriss` repo as a base. It is Next.js + Tailwind; the
  spec asks for Vite and "no heavy libraries", so only the process and
  tooling were taken: AGENTS.md, tokens with dark/light themes, the `verify`
  gate, lint file-length limits, TRAPS format, CI workflow, native `<dialog>`.
- Decisions not in the spec (all reversible):
  - `Media` gained optional `size`, `mtime` (skip re-hashing unchanged files),
    `missing` (vanished files are marked, not deleted) and `altPaths`
    (byte-identical duplicates collapse into one item).
  - `exportedTo[].series` stores the series **id**.
  - Arrow keys skip filtered (greyed) items; ↑/↓ rate the whole selection when
    there is one, and undo treats that as one step.
  - Title "place" = edited place, else the nearest folder name that isn't a
    camera folder (DCIM, 100APPLE, dates …). There is no reverse geocoding —
    that would need the network.
  - `P` focuses the place field (applies to the selection).
- The user asked how their brother could use it on an iPad → answered in
  README § iPad; no code yet.

# 2026-10-21 — Phone, deletion, trimming

The user tried it on an **iPhone** (screenshot: header items overlapping, the
dock cut off on the right, the card over the date) and asked for:

1. **Phone is "extremely important"** — rating on the go. → Phone layout
   (≤ 600 px): compact header with a ⋯ menu, a seven-target dock, cards laid
   out between the measured date and dock, shorter waveform.
2. **The lowest level should delete**, "into 30 days until deleted", and the
   app should "really delete in the end, from the folder or wherever".
   → Discards get `discardedAt`; folder mode deletes them 30 days later on
   open, or on a confirmed "Delete now". This **changes hard rule 1** in
   AGENTS.md on the user's request. Files mode cannot delete (browser); the
   list stays a checklist.
3. **Trim videos**; what is cut away is deleted, the rest kept. → mediabunny
   packet copy (lossless, no decoder needed). Folder: the trimmed file
   replaces the original, which waits 30 days in `_reel_trash/` (`bin`).
   Files: shared via "Save to Photos", the original becomes a discard.
4. **Adding videos from the gallery hangs** — "only possible natively?"
   → The wait is iOS copying/converting videos before the browser gets them;
   a web page cannot see or speed it up. Added a "Waiting for your photos…"
   overlay so it no longer looks frozen. A native app (Capacitor + PhotoKit)
   would read the library directly — offered, not built.
5. **Folder selection** (the message was cut off after "und eben"). iOS
   Safari has no folder picker as such; `webkitdirectory` is now offered on
   touch as "From the Files app (folder)" — what it does depends on the iOS
   version (LIVE CHECK).

Found on the way: taps on the upper part of a card missed (3D hit test) —
see TRAPS.
