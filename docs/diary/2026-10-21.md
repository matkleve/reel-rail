# 2026-10-21 — Phase 1

- Spec came in German; the user asked for **everything in English** (UI copy,
  code, docs).
- User offered the `grundriss` repo as a base. It is Next.js + Tailwind; the
  spec asks for Vite and "no heavy libraries", so only the process and
  tooling were taken: AGENTS.md, tokens with dark/light themes, the `verify`
  gate, lint file-length limits, TRAPS format, CI workflow, native `<dialog>`.
- Decisions not in the spec (all reversible):
  - `Media` gained optional `size`, `mtime` (skip re-hashing unchanged files),
    `missing` (vanished files are marked, not deleted) and `altPaths`
    (byte-identical duplicates collapse into one item).
  - `exportedTo[].series` stores the series **id**.
  - Arrow keys skip filtered (greyed) items; ↑/↓ rate the whole selection when
    there is one, and undo treats that as one step.
  - Title "place" = edited place, else the nearest folder name that isn't a
    camera folder (DCIM, 100APPLE, dates …). There is no reverse geocoding —
    that would need the network.
  - `P` focuses the place field (applies to the selection).
- The user asked how their brother could use it on an iPad → answered in
  README § iPad; no code yet.

# 2026-10-21 — Phase 2 + redesign

- **User redesigned the main view mid-phase-2** (correction → invariant):
  - Photos side by side as a **carousel** (reference: a coverflow with the
    centre card big, side cards smaller and turned). ↓ makes a card smaller
    and it slides down; favourites get bigger and rise. Slight 3D surface.
  - Bottom: a **waveform** timeline — thick where many media were taken,
    click to jump.
  - **Space** = copy to a "download / reuse" folder → implemented as the
    *picks folder* (chosen once, remembered; Space again takes the copy back,
    only if unchanged). Video play/pause moved to V, mute to M.
  - The thumbnail rail and its dot-zoom were removed; the spec's zoom
    (hours ↔ day ↔ trip) now lives on the waveform.
- Phase 2 otherwise as specified: tags 1–9 + T + filter + presets dialog,
  bursts (<3 s, Enter, X), cleanup to `_reel_trash/`.
- Thumbnails are 480 px now (side cards are big).
- **Hosting:** the user asked to publish on Vercel with a password. Vercel's
  built-in password protection is a paid add-on, so `middleware.ts` serves a
  login page and sets a hashed cookie; the password is the `REEL_PASSWORD`
  env var. Cookie instead of Basic Auth because Basic Auth is flaky in
  installed iPad web apps.

# 2026-10-21 — five levels + glowing waveform

- User feedback on the waveform (reference: colourful glowing sound waves):
  colour per tag; the wave goes **up where the photos are good, down where
  they are weak**; and **five rating levels** — favorite, good, normal, not
  great, discard (2 … −2).
- `.reel.json` → version 2; v1's −1 ("unusable") is migrated to −2.
- Waveform: one translucent, additively blended wave per tag (top 9 tags,
  rest neutral), centred on the bin's average rating, Gaussian-smoothed;
  white spine = overall average; one spark per medium.
- "Unusable" view/filter renamed to "Discards".

# 2026-10-21 — design system & UX pass

- User: "it looks horrible — get a good design system". Diagnosis: a dozen
  equal-weight pills in the top bar, Unicode glyphs as icons, a thick orange
  frame on the current photo, rating only by keyboard, no type or spacing
  system.
- Built `docs/DESIGN-SYSTEM.md` + three-layer tokens (neutral greys so the
  chrome never tints photos; one warm accent), Inter, lucide icons, and a
  kit (`src/ui/kit/`): Button (with tooltip + shortcut), Kbd, Segmented,
  Switch, Popover (native), Dialog.
- UX changes: spotlight instead of a frame; floating dock with a clickable
  five-level rating, tags and Pick; selection bar; date/place typography over
  the stage with inline place editing; first-run key hints; grouped shortcut
  overlay; new start screen; empty states.
- "Hide discards" became its own switch (it used to exclude the other rating
  filters).
